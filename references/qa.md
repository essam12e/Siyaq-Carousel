# فحص الجودة قبل التسليم

## آلي (qc-report.md / qc-report.json) — يُنتج مع كل render
| الرمز | المعنى | المستوى |
|---|---|---|
| `TEXT_OVERFLOW` / `EXACT_TEXT_CONFLICT` | النص لا يتسع حتى بأصغر مقياس / نص حرفي لا يتسع | خطأ |
| `OUT_OF_BOUNDS` / `OUTSIDE_SAFE_AREA` / `IMPORTANT_OUTSIDE_SAFE` | نص أو شعار/CTA/QR خارج الصورة أو المنطقة الآمنة | خطأ |
| `TEXT_OVERLAP` | نصوص متداخلة | خطأ |
| `FONT_LOAD_FAILED` / `SYSTEM_FONT_FALLBACK` / `USER_FONT_FALLBACK` | خط لم يُحمّل أو رُسم بخط آخر (يُقاس من المتصفح عبر CDP) | خطأ/تنبيه |
| `USER_FONT_MISSING_GLYPHS` / `FONT_NO_ARABIC` | خط ينقصه حروف النص (قبل الرسم) | إيقاف |
| `LOW_CONTRAST` | تباين مقاس من بكسلات الصورة أقل من 4.5 (أو 3 للكبير) | تنبيه / خطأ تحت 2.2 |
| `IMAGE_NOT_LOADED` / `IMAGE_DISTORTED` / `IMAGE_UPSCALED` | صورة لم تظهر / ممطوطة / مكبرة فوق دقتها | خطأ/تنبيه |
| `PRODUCT_CLIPPED` / `PRODUCT_CROPPED` | المنتج مقصوص | خطأ |
| `QR_TOO_SMALL` | QR أصغر من max(200px, 20% من الضلع الأقصر) | خطأ |
| `PLACEHOLDER_TEXT` | نص مؤقت (lorem، «اكتب هنا»…) | إيقاف |
| `SEAM_MISMATCH` | حواف العنصر المتصل لا تتطابق | تنبيه |
| `SLIDE_COUNT` / أبعاد PNG | عدد الصور أو أبعادها لا تطابق المطلوب | خطأ |
| `DECOR_HIDDEN` / `TEXT_SCALED` | زخرفة أُخفيت لأنها تلمس نصًا / تم تصغير الخط | معلومة |

لا يُنشأ ZIP إذا وُجد خطأ (إلا بـ `--force` للتشخيص).

## بصري (إلزامي — افتح contact-sheet.png)
- [ ] العربية متصلة وصحيحة الاتجاه، لا حروف مربعة، لا كلمات مقلوبة، الأرقام والحسابات سليمة.
- [ ] الهرمية واضحة: عين القارئ تبدأ بالعنوان. لا شريحة مزدحمة ولا شريحة نصفها فارغ بلا قصد.
- [ ] التباين مريح، خصوصًا فوق الصور والتدرجات.
- [ ] المنتج مطابق للصورة الأصلية (شكل، ألوان، شعار) وغير مقصوص.
- [ ] CTA واضح وفي المكان الصحيح، والأيقونات للحسابات المعطاة فقط.
- [ ] الاستمرارية: افتح continuity-strip.png وتأكد أن العنصر متصل بلا قفزات.
- [ ] لا نصوص مؤقتة أو إنجليزية متبقية، لا علامة نطاق داخل التصميم.
- [ ] الأسلوب متسق عبر الشرائح والتكوين متنوع.

إصلاح شريحة: عدّل الـspec ثم `render … --slides N`. النسخة السابقة تُحفظ في `versions/`.

## اتساق التصدير
`node scripts/siyaq.mjs verify OUT` يعيد رسم ملفات HTML القابلة للتعديل ويقارنها بالـPNG المسلّمة بكسلًا بكسلًا.
